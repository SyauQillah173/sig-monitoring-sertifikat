6. SERTIFIKAT SISTEM ISO SEMEN
--------------------------------------------------
Konsep:
- Sertifikat Sistem tetap domain semen.
- Relasi utama: lokasi_pabrik_id dan iso_standard_id.
- ISO bukan ditempel langsung ke merek semen.
- Scope dipakai untuk menulis cakupan seperti "Produksi semen".

Standar ISO awal:
- ISO 9001  : Sistem Manajemen Mutu
- ISO 14001 : Sistem Manajemen Lingkungan
- ISO 45001 : Sistem Manajemen K3
- ISO 50001 : Sistem Manajemen Energi
- ISO 37001 : Sistem Manajemen Anti Penyuapan
- ISO 27001 : Sistem Manajemen Keamanan Informasi

Tahap audit:
- Surveilen 1
- Surveilen 2
- Renewal

Field korporasi sertifikat sistem:
- acquisition_year
- certification_level: nasional / internasional
- certification_category
- process_owner
- accreditation_number
- public_url
- description

Timeline audit:
- Tabel: sertifikat_sistem_audit_events
- Model: App\Models\SertifikatSistemAuditEvent
- Service: App\Services\SystemCertificateAuditTimelineService
- Event: initial, surveilen_1, surveilen_2, renewal
- Bukti audit private download route: cement.system-audit-evidence.download

Command:
- php artisan system:backup
- php artisan system:backup --force
- php artisan system:backup-cleanup

Schedule:
- Backup harian jam 01:30.
- Cleanup mingguan Senin jam 02:30.
- Scheduler didefinisikan di routes/console.php.

Penyimpanan:
- File backup private di storage/app/private/backups.
- Riwayat di tabel database_backups.
- Backup berisi database.sql, metadata.json, dan file storage jika opsi aktif.

Catatan:
- MySQL backup memakai mysqldump.
- Pada XAMPP Windows default dicari di C:\xampp\mysql\bin\mysqldump.exe.
- Jika beda lokasi, pakai BACKUP_MYSQLDUMP_PATH di .env.
- Jangan simpan backup di public folder.
- Download backup hanya admin dan tercatat audit log.
