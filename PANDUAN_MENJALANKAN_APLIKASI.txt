1. MASUK KE FOLDER PROYEK
--------------------------------------------------
Buka CMD atau PowerShell, lalu jalankan:

cd /d C:\xampp\htdocs\SIG

Jika berhasil, posisi terminal berada di:

C:\xampp\htdocs\SIG>


2. NYALAKAN XAMPP
--------------------------------------------------
Buka XAMPP Control Panel, lalu nyalakan:

- Apache
- MySQL

Yang wajib untuk Laravel adalah MySQL.
Apache boleh menyala, tetapi untuk development lebih disarankan memakai php artisan serve.


3. BUAT DATABASE
--------------------------------------------------
Buka:

http://localhost/phpmyadmin

Buat database:

monitoring_sertifikat


4. CEK FILE .ENV
--------------------------------------------------
Pastikan konfigurasi utama seperti ini:

APP_NAME="SIG Monitoring Sertifikat"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://127.0.0.1:8082

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=monitoring_sertifikat
DB_USERNAME=root
DB_PASSWORD=

QUEUE_CONNECTION=sync
FILESYSTEM_DISK=local

MAIL_MAILER=log
MAIL_FROM_ADDRESS="managementsystembpe@gmail.com"
MAIL_FROM_NAME="${APP_NAME}"

Catatan:
- Jika password MySQL XAMPP kosong, biarkan DB_PASSWORD kosong.
- MAIL_MAILER=log artinya email belum benar-benar dikirim, hanya dicatat ke log.
- Jika memakai Gmail SMTP, MAIL_PASSWORD wajib App Password Gmail, bukan password login biasa.
- Jika app password Gmail berisi spasi, hapus spasinya atau bungkus dengan tanda kutip.
- APP_URL harus sama dengan alamat server yang sedang dipakai. Jika menjalankan server di 127.0.0.1:8082, APP_URL juga harus http://127.0.0.1:8082 agar link email notifikasi bisa dibuka.


5. INSTALL DEPENDENCY
--------------------------------------------------

composer install
npm install

Kalau dependency sudah pernah diinstall, langkah ini biasanya tidak perlu diulang.

9. JALANKAN SERVER LARAVEL
--------------------------------------------------
Cara utama:

php -d auto_prepend_file= -d max_execution_time=120 -S 127.0.0.1:8082 -t public

Buka browser:

http://127.0.0.1:8082

Alternatif Laravel bawaan:

php artisan serve

Jika memakai php artisan serve, biasanya browser dibuka di:

http://127.0.0.1:8000

Jika terminal memakai PHP Herd dan muncul error lambat/timeout seperti
"Maximum execution time of 30 seconds exceeded", gunakan command yang lebih aman:

php -d auto_prepend_file= -d max_execution_time=120 -S 127.0.0.1:8082 -t public

Buka:

http://127.0.0.1:8082

Jika memakai port 8082, pastikan .env berisi:

APP_URL=http://127.0.0.1:8082

Setelah mengubah APP_URL, jalankan:

php artisan config:clear
php artisan optimize:clear

12. RESET PASSWORD DENGAN KODE EMAIL
--------------------------------------------------
Alur reset password:

1. Klik "Lupa password?" di halaman login.
2. Masukkan email login yang sudah didaftarkan admin.
3. Sistem mengirim kode 6 digit ke email tersebut.
4. Masukkan kode di halaman "Masukkan kode reset".
5. Jika kode benar, sistem membuka halaman password baru.
6. Isi password baru dan konfirmasi password.

Jika muncul pesan kode gagal dikirim:
- Cek MAIL_MAILER, MAIL_HOST, MAIL_PORT, MAIL_USERNAME, MAIL_PASSWORD.
- Pastikan Gmail memakai App Password.
- Jalankan:

php artisan config:clear


13. SETTING EMAIL SMTP
--------------------------------------------------
Default aplikasi memakai:

MAIL_MAILER=log

Artinya email reset password dan email notifikasi belum benar-benar keluar.

Jika ingin memakai Gmail sementara, isi .env seperti ini:

MAIL_MAILER=smtp
MAIL_SCHEME=null
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=managementsystembpe@gmail.com
MAIL_PASSWORD=ISI_APP_PASSWORD_GMAIL
MAIL_FROM_ADDRESS="managementsystembpe@gmail.com"
MAIL_FROM_NAME="${APP_NAME}"

Penting:
- Jangan tulis password SMTP di file dokumentasi.
- Gunakan App Password Gmail, bukan password login biasa.
- App Password Gmail dibuat dari Google Account > Security > App passwords.
- Setelah mengubah .env, jalankan:

php artisan config:clear

Lalu test dari menu:

Pemeliharaan Data > Pengaturan Email & Notifikasi > Test Email

Test koneksi SMTP dari PowerShell Windows:

Test-NetConnection smtp.gmail.com -Port 587

Kalau TcpTestSucceeded True, jaringan bisa menjangkau Gmail SMTP.


14. NOTIFIKASI OTOMATIS
--------------------------------------------------
Command internal lama:

php artisan notifications:generate-certificate-expiry

Command email sertifikat semen:

php artisan cement:send-certificate-email-notifications

Fitur terbaru notifikasi ISO:
- Sistem membaca data Sertifikat Sistem ISO Semen.
- Notifikasi internal dibuat untuk user role admin dan petugas.
- Email reminder menampilkan tabel seperti contoh lama: ISO, lokasi/pabrik, tanggal berlaku, jenis tindak lanjut, status, dan aksi.
- Tombol aksi email/internal:
  - Ubah Status S1
  - Ubah Status S2
  - Input Data Baru untuk Renewal
- Tombol dari email tidak langsung mengubah data. Tombol membuka form konfirmasi di web agar aman.
- Jika belum login, user diarahkan login dulu.
- Hanya admin dan petugas yang dapat mengakses dashboard aplikasi sesuai hak aksesnya.

Route tindak lanjut ISO:
- /sertifikat-sistem/{id}/tindak-lanjut/surveilen_1
- /sertifikat-sistem/{id}/tindak-lanjut/surveilen_2
- /sertifikat-sistem/{id}/tindak-lanjut/renewal

Cara test manual:

1. Pastikan server jalan di alamat yang sama dengan APP_URL.
2. Jalankan:

   php artisan cement:send-certificate-email-notifications

3. Buka email terbaru yang masuk.
4. Klik Ubah Status S1, Ubah Status S2, atau Input Data Baru.
5. Login sebagai admin/petugas jika diminta.
6. Form tindak lanjut harus terbuka di web.

Catatan:
- Email lama tidak berubah otomatis jika APP_URL sebelumnya salah.
- Setelah memperbaiki APP_URL, wajib kirim ulang email notifikasi.
- Untuk lokal sekarang gunakan APP_URL=http://127.0.0.1:8082 jika server aktif di 8082.

Schedule otomatis ada di:

routes/console.php

Untuk server production, scheduler Laravel perlu dijalankan oleh cron/Task Scheduler.
Untuk development lokal, command bisa dijalankan manual.

Untuk menjalankan scheduler lokal selama development:

php artisan schedule:work

Jika hanya ingin menjalankan command notifikasi manual:

php artisan notifications:generate-certificate-expiry
php artisan cement:send-certificate-email-notifications


15. TWO FACTOR AUTHENTICATION / 2FA
--------------------------------------------------
2FA memakai Laravel Fortify berbasis TOTP/authenticator app.

Aplikasi yang bisa dipakai:
- Google Authenticator
- Microsoft Authenticator
- Authy
- aplikasi lain yang mendukung TOTP

Alur:
1. Login.
2. Buka Pengaturan Akun > Keamanan.
3. Aktifkan Two Factor Authentication.
4. Scan QR Code dengan aplikasi authenticator.
5. Masukkan kode dari aplikasi untuk konfirmasi.
6. Simpan recovery code.

Jika 2FA sudah aktif dan terkonfirmasi:
- Saat login berikutnya, setelah password benar, sistem otomatis meminta kode 2FA.
- User bisa memakai recovery code jika HP/authenticator tidak bisa diakses.

Catatan:
- Kode email/Gmail saat ini dipakai untuk reset password, bukan metode 2FA login.
- Jika nanti ingin 2FA via email OTP, perlu dibuat fitur tambahan.

19. BACKUP & MAINTENANCE SISTEM
--------------------------------------------------
Menu:

Pengaturan Sistem > Backup & Maintenance

Fungsi:
- Membuat backup manual dari web admin.
- Menampilkan riwayat backup.
- Download file backup.
- Hapus backup.
- Cleanup backup lama.
- Mengatur backup otomatis, retensi hari, dan maksimal jumlah backup.
- Health check sederhana untuk warning production dan relasi data.

File backup disimpan private di:

storage/app/private/backups

Tabel riwayat backup:

database_backups

Command backup manual dari terminal:

php artisan system:backup --force

Command backup otomatis:

php artisan system:backup

Command cleanup:

php artisan system:backup-cleanup

Schedule otomatis:
- Backup setiap hari jam 01:30.
- Cleanup setiap Senin jam 02:30.

Untuk membuat schedule berjalan terus saat lokal:

php artisan schedule:work

Untuk production:
- Pasang cron/Task Scheduler agar menjalankan php artisan schedule:run setiap menit.

Catatan MySQL/XAMPP:
- Backup MySQL memakai mysqldump.
- XAMPP Windows biasanya memakai:
  C:\xampp\mysql\bin\mysqldump.exe
- Jika mysqldump tidak ditemukan, tambahkan di .env:
  BACKUP_MYSQLDUMP_PATH=C:\xampp\mysql\bin\mysqldump.exe

Keamanan backup:
- File backup tidak boleh dipindah ke public folder.
- Download backup hanya untuk admin.
- Download/hapus backup tercatat di audit log.
- Jika backup menyertakan file private, isinya termasuk file sertifikat dan bukti audit.

23. ERROR YANG SERING MUNCUL
--------------------------------------------------
Error "Unknown database monitoring_sertifikat":
- Database belum dibuat di phpMyAdmin.

Error "could not find driver":
- Ekstensi pdo_mysql PHP belum aktif.

Error "Connection refused":
- MySQL belum menyala.

Error "Vite manifest not found":
- Jalankan npm install lalu npm.cmd run build.

Error "npm.ps1 cannot be loaded":
- Gunakan npm.cmd run dev atau CMD biasa.

Error "Failed to listen on 127.0.0.1:8000":
- Port dipakai aplikasi lain.
- Pakai alternatif:
  php -S 127.0.0.1:8082 -t public

Error "Maximum execution time of 30 seconds exceeded" saat membuka halaman:
- Biasanya terjadi karena cache Laravel/Composer sedang berat atau PHP Herd memasang auto_prepend_file.
- Stop server dengan Ctrl+C.
- Jalankan:
  php artisan optimize:clear
- Jika masih lambat, jalankan server dengan:
  php -d auto_prepend_file= -d max_execution_time=120 -S 127.0.0.1:8082 -t public
- Jika ada proses PHP/Composer lama yang menggantung, tutup dari Task Manager atau restart terminal.

Error dotenv "unexpected whitespace" pada MAIL_PASSWORD:
- App password Gmail mengandung spasi.
- Hapus spasi atau bungkus value dengan tanda kutip.
- Jalankan php artisan config:clear.

Email tidak terkirim:
- Cek MAIL_MAILER.
- Cek MAIL_HOST, MAIL_PORT, MAIL_USERNAME, MAIL_PASSWORD.
- Jalankan php artisan config:clear.
- Pastikan email otomatis di menu Pengaturan Email & Notifikasi sudah aktif.

Backup gagal karena mysqldump tidak ditemukan:
- Pastikan XAMPP MySQL terinstall.
- Cek file:
  C:\xampp\mysql\bin\mysqldump.exe
- Tambahkan ke .env:
  BACKUP_MYSQLDUMP_PATH=C:\xampp\mysql\bin\mysqldump.exe
- Jalankan:
  php artisan config:clear

Backup otomatis tidak jalan:
- Scheduler belum aktif.
- Untuk lokal jalankan:
  php artisan schedule:work
- Untuk production pasang cron/Task Scheduler untuk:
  php artisan schedule:run
